 # TRWM Explained

 This document is in progress.

## Introduction

TRWM (Technique Results Weaknesses Mitigations) is a systematic approach for capturing the details of a digital forensic techqniue *and* then enumerating over its potential weaknesses and mitigations.

It is supported by TRWM Helper Workbooks (which are Google Sheets workbooks).


A class exercise that works through the process is provided in the [Class Exercises](../class-exercises//class-exercises.md) section.
