# Contributing to SOLVE-IT: A Guide for Digital Forensic Researchers

If you are a digital forensics researcher then there is a good chance that you are carrying out and publishing work that could be added to the SOLVE-IT knowledge base. 

This document should provide you with the details needed to add your work to the knowledge base. Page 2 contains a Quick Start Guide, with more detail provided in the later sections.


This guide will migrate to markdown at some point, but for now a PDF version of the guide for digital forensic researchers is available [here](contributing_to_SOLVE-IT_-_A_guide_for_researchers.pdf).
